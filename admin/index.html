Dashboard setup needed

The dashboard needs a Firebase project. Until then, the website reads the files in the data folder.

  1. Create a Firebase project and a Web app.
  2. Paste its config into js/config.js.
  3. Turn on Email/Password sign-in and create Firestore.
  4. Publish the rules from firestore.rules.

Step-by-step instructions are in README.md.
